高品质 3D 卡通休闲跳跃 Web 游戏，以可爱“奶蛙”为主角。

## 游戏快速启动方式

### 方式一：一键双击运行（最推荐）
直接双击运行目录下的 **`启动游戏.bat`**（或 `start_game.bat`）。
脚本会自动检测环境，秒级启动本地 HTTP 服务并在默认浏览器中直接打开游戏！

### 方式二：双击 `index.html` 直接打开
项目已内置 `model_data.js` 离线模型数据与本地 Three.js 依赖，在主流浏览器中直接双击 `index.html` 即可畅玩，不受网络或 CDN 波动影响。

### 方式三：拖拽任意资源载入
如果浏览器因极高安全策略拦截了外部文件请求，直接把目录中的 `naiwa.zip` 或 `naiwa.glb` 文件拖拽进浏览器窗口，游戏将利用内置解压与解析器瞬间载入！

## 核心机制与玩法特色

1. **真实抛物线物理与程序化萌趣动画**：
   - **待机**：慢速微幅呼吸 Wobble。
   - **蓄力**：身体纵向受压下瘪、横向饱满外凸，微向后坐，蓄力条动态充能，音调平滑上升。
   - **起跳**：瞬间垂直拉伸，脚底爆发圆环尘埃粒子。
   - **空中**：沿抛物线轨迹前倾俯冲，眼望目标平台。
   - **落地**：受到冲击剧烈下压，随后通过阻尼弹簧振子弹性回弹，真实重量感十足。
   - **踏空掉落**：重心失衡失控翻滚坠入云海，摄像机俯冲跟随。

2. **落点精准判定与连击奖励**：
   - **PERFECT!**（落入平台中心 30% 范围）：+30分，触发连续 Combo 乘数加成，金黄四芒星光束喷发，清脆琶音和弦！
   - **GREAT!**（落入中心 60% 范围）：+20分，双音风铃反馈。
   - **GOOD**（落入中心 90% 范围）：+15分。
   - **LANDED**（踩在平台边缘）：+10分。
   - **黄金奖励台**：随机刷出闪耀黄金柱台，命中额外奖励 +25 分！

3. **视觉与原声音频系统**：
   - 清新马卡龙低多边形风格：薄荷绿、奶油黄、海盐蓝、蜜桃粉多彩圆柱与阶梯台座。
   - 动态云海游弋、远景群山与暖阳柔影。
   - **双轨沉浸背景音乐**：主菜单待机播放《背景音乐(点击开始游戏后2s淡出).mp3》，点击开始后 2 秒内平滑淡出，随后无缝淡入《游戏中背景音乐(循环播放).mp3》。
   - **动态加速蓄力**：蓄力时播放《UI点击&蓄力.mp3》，播放速率（playbackRate）随蓄力深度从 0.70x（慢速）平滑加速至 1.85x（高速），完美贴合能量充盈动势。
   - **真实敲击反馈**：落地触发《落地音效.mp3》，并随命中评级叠加空灵清脆的奖励和弦。
   - **失误与结算反馈**：踩空掉落触发专属《失败音效.mp3》，同时智能压低背景音乐。
   - **全场景容灾**：同时集成 Web Audio API 纯程序化合成引擎，任何网络或隔离环境均可完美发声。
   - 本地 `localStorage` 自动记录历史最高分、最高连击与总 Perfect 场次。
